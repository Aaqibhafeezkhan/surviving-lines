# Roadmap

Three next steps, in no particular order. Open an issue if you want to take one.

- `--by name` to merge identities without a `.mailmap` (issue #10)
- A `--since/--until` window for the blame side (issue #11; blame at a past ref is already possible with `--ref`)
- Several repositories, or submodules, in one run (issue #34)

Things deliberately not planned: anything that needs a server, a hosted account, or reads code content.
